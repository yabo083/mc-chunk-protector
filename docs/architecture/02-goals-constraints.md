# 目标、约束与质量需求

## 目标

1. OP 能用短命令批量保护矩形，也能逐区块添加或移除，组合出不规则区域。
2. 配置变更立即生效，并可通过文件热重载。
3. 在百万到千万区块地图上，成本由保护矩形和实际方块更新决定，而不是地图或保护面积。

## 约束

- MC 1.21.1 / NeoForge 21.1.219 / Java 21。
- 服务器侧 mod；客户端不要求安装。
- 唯一持久化契约是 `kubejs/config/regions.json`，路径不表示 KubeJS 依赖。
- 区块坐标按维度独立，矩形边界为闭区间。

## 质量需求

- 热判定读取不可变空间桶索引，无磁盘 IO、JSON 解析、装箱或按覆盖区块展开。
- 40 server ticks 一次的配置检查是全服务器一次，不是逐区块扫描。
- `/cpor` 仅权限等级 2 可见和执行；坐标、文件大小、矩形数和索引复杂度均有限制。
- 命令写入先完整验证，再用同目录临时文件原子替换；失败保留旧文件和旧快照。
- 冷路径编辑最多处理 8192 个目标模式矩形，避免在服务器线程上进行无界几何工作。
